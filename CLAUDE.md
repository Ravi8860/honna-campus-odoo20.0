# Odoo 20 Development Rules

- Analyze the existing code before editing.
- Preserve all existing user modifications.
- Work only on the requested functionality.
- Make minimal changes to existing code.
- Do not create unnecessary helper methods.
- Follow Odoo 20 coding conventions.
- Validate Python and XML changes.
- Review git diff after implementation.
- Never reset, clean, or discard existing changes.
- Never commit, push, upgrade a module, or deploy without explicit approval.
